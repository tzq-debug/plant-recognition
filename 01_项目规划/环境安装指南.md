# 🔧 第一步：环境配置详细指南

## ⚡ 快速安装（推荐顺序）

### 1️⃣ 检查当前Python环境
```bash
# 打开命令提示符或PowerShell
python --version
# 应该显示 Python 3.8+ 
```

如果没有Python，先安装：
- 访问 https://python.org/downloads
- 下载 Python 3.8 或更高版本
- 安装时勾选 "Add Python to PATH"

### 2️⃣ 创建专用环境（强烈推荐）
```bash
# 创建植物识别专用环境
conda create -name plant_recognition python=3.8

# 激活环境
conda activate plant_recognition
```

如果没有conda，使用pip：
```bash
# 创建虚拟环境
python -m venv plant_recognition

# Windows激活
plant_recognition\Scripts\activate

# Linux/Mac激活  
source plant_recognition/bin/activate
```

### 3️⃣ 安装核心库（按顺序执行）
```bash
# 安装PyTorch（最重要）
pip install torch torchvision

# 安装FastAI（最简单）
pip install fastai

# 安装辅助库
pip install pandas numpy matplotlib pillow
pip install scikit-learn opencv-python
```

## 🚀 一键安装脚本

### Windows批处理文件
```batch
@echo off
echo 🔧 开始安装植物识别环境...

echo 1. 检查Python...
python --version
if errorlevel 1 echo ❌ 请先安装Python 3.8+ & pause & exit

echo 2. 创建conda环境...
conda create -name plant_recognition python=3.8 -y

echo 3. 激活环境...
conda activate plant_recognition

echo 4. 安装PyTorch...
pip install torch torchvision

echo 5. 安装FastAI...
pip install fastai

echo 6. 安装辅助库...
pip install pandas numpy matplotlib pillow scikit-learn

echo ✅ 安装完成！
echo 使用方法：conda activate plant_recognition
echo 然后运行：python D:\植物识别项目\03_代码开发\完整训练脚本.py

pause
```

保存为：`D:\植物识别项目\01_项目规划\一键安装.bat`

## ⚠️ 常见安装问题

### 问题1：torch安装失败
```bash
# 解决方案：指定版本
pip install torch==1.9.0 torchvision==0.10.0

# 或者使用conda
conda install pytorch torchvision
```

### 问题2：网络连接问题
```bash
# 使用国内镜像
pip install torch -i https://pypi.tuna.tsinghua.edu.cn/simple

pip install fastai -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题3：权限问题
```bash
# Windows：以管理员身份运行命令提示符
# 或者添加 --user 参数
pip install torch --user
```

### 问题4：CUDA版本不匹配
```python
import torch
print(torch.cuda.is_available())  # 查看CUDA是否可用

# 如果显示False，使用CPU版本
pip install torch torchvision --no-cuda
```

# 🌱 植物识别AI项目

基于深度学习的植物自动识别系统，能够通过图片准确识别10种常见植物。

## 🎯 项目特色
- **新手友好**：使用FastAI框架，代码简洁易懂
- **快速部署**：10分钟即可训练完成
- **GUI界面**：提供图形化操作界面
- **持续学习**：支持扩展更多植物种类

## 🛠️ 技术栈
- **深度学习**：PyTorch + FastAI
- **图像处理**：PIL, OpenCV
- **数据处理**：Pandas, NumPy
- **可视化**：Matplotlib
- **界面**：Tkinter

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install torch torchvision fastai pandas numpy matplotlib pillow scikit-learn
```

### 2. 数据收集
为每种植物收集20-30张图片到对应文件夹：
- 玫瑰、向日葵、百合、菊花、兰花
- 仙人掌、竹子、枫树、松树、荷花

### 3. 训练模型
```python
python 03_代码开发/完整训练脚本.py
```

### 4. 测试应用
训练完成后会自动生成GUI界面，可以上传图片进行植物识别。

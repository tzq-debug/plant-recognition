# DataTracker 微信小程序
## 数据记录仪 - 帮助你记录和分析生活的每一天

### 📱 项目介绍
DataTracker是一个专注于健康数据记录的微信小程序，帮助用户：
- 记录每日运动步数
- 监测睡眠质量
- 跟踪饮水量
- 分析健康趋势
- 设置智能提醒

### 🎯 核心功能
1. **运动数据** - 自动同步微信运动步数，手动记录运动项目
2. **睡眠监测** - 记录睡眠时间，分析睡眠质量
3. **饮水提醒** - 智能提醒喝水，记录每日饮水量
4. **数据可视化** - 图表展示健康数据趋势
5. **智能提醒** - 个性化健康提醒和建议

### 🛠️ 技术特点
- 微信小程序原生开发
- 组件化架构设计
- 本地数据存储
- 响应式UI设计
- 轻量级图表库

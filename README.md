# 🌱 植物识别项目

## 项目简介
本项目旨在构建一个自动识别植物的深度学习模型，通过图像分类技术准确识别不同植物种类。

## 🚀 快速开始

### 环境准备
```bash
# 创建Python虚拟环境
conda create -name plant_id python=3.8
conda activate plant_id

# 安装基础库
pip install torch torchvision
pip install fastai pandas numpy
pip install matplotlib pillow
```

### 第一个任务
1. 下载10种常见植物的图片数据
2. 使用FastAI框架构建基础模型
3. 实现简单的图像分类功能

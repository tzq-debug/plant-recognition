# 🌱 Plant Recognition AI Project

## 🌿 Overview
An AI-powered plant identification system using deep learning to accurately recognize 10 common plant species from images.

## 🎯 Features
- **Beginner Friendly**: Built with FastAI framework for easy understanding
- **Quick Deployment**: Train completes in 10 minutes
- **GUI Interface**: Graphical user interface for easy operation
- **Continuous Learning**: Expand to more plant species
